منظّم الجامعة (UniHub)
======================

التشغيل لأول مرة
----------------
1. شغّل الملف UniHub.exe (إذا ظهرت رسالة Windows SmartScreen اضغط "مزيد من المعلومات" ثم "تشغيل على أي حال").
2. يفتح البرنامج في المتصفح. اضغط "تثبيت" في الشريط العلوي ليضاف إلى قائمة ابدأ وسطح المكتب.
3. اربط حساب المودل: رابط الموقع + الرقم الجامعي + كلمة المرور (كلمة المرور لا تُحفظ).
4. انتظر قليلاً حتى تنزل المحاضرات والواجبات وتُرتّب في مجلد "الجامعة - مرتب" على سطح المكتب.

التحديثات
---------
البرنامج يتحدث تلقائياً من GitHub. بياناتك محفوظة في:
  %AppData%\UniHub
ولا يلمسها التحديث، ويحفظ نسخة احتياطية منها قبل كل تحديث في مجلد backups.
ملفات الجامعة المرتبة لا تُحذف ولا تُنقل أبداً.

الملاحظات الفنية
----------------
من قسم "الملاحظات الفنية" داخل البرنامج: اربط حساب GitHub مرة واحدة ثم أرسل
أي خطأ أو اقتراح، وتصل للطرف الآخر مع تنبيه. بدون إنترنت تُحفظ وتُرسل لاحقاً.

اختصارات
--------
/ أو Ctrl+K : البحث       الأسهم + Enter : فتح النتيجة       Ctrl+Enter : إظهار في المجلد
