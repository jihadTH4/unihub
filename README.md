<h1 align="center">منظّم الجامعة</h1>
<p align="center">ترتيب محاضرات وواجبات المودل تلقائياً، إشعارات ومواعيد، ومحرك بحث سريع داخل كل الملفات.</p>

## التنزيل

من صفحة التنزيل: **https://jihadth4.github.io/unihub/**

- **ويندوز**: [UniHub.exe](../../releases/latest/download/UniHub.exe)
- **أندرويد** (8 فأحدث): [UniHub.apk](../../releases/latest/download/UniHub.apk)

تنزّله مرة واحدة فقط، وبعد ذلك يتحدث البرنامج تلقائياً.

## المزايا

- مزامنة مع المودل: مجلد لكل مادة، وبداخله محاضرات / واجبات / امتحانات، ومجلد خاص لكل واجب فيه «حلّي».
- إشعارات المودل والمواعيد القادمة مع تنبيهات على الكمبيوتر والجوال.
- بحث فوري في أسماء الملفات ومحتواها (PDF وWord وPowerPoint وExcel) بالعربي والإنجليزي.
- «صوري»: جدول الامتحانات والخطة الدراسية وإشعارات الدفع وكل صور الجامعة، مع لصق لقطات الشاشة مباشرة وتثبيت المهم في الرئيسية.
- «روابطي»: بوابة الطالب وصفحات وموقع جامعتك في الشريط الجانبي، خاصة بكل مستخدم.
- ثيم فاتح / داكن / تلقائي يتبع النظام.
- تحديث تلقائي آمن من GitHub مع نسخة احتياطية للبيانات.
- قسم «الملاحظات الفنية» لإرسال الأخطاء والاقتراحات بين المستخدمين عبر Issues.
- يعمل بدون إنترنت، ويزامن عند توفر الاتصال.
